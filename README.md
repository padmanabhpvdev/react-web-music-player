## Requirements
**NodeJS** and **React**
## How to use ?

Install the app using following code or download the ZIP:

```
git clone https://github.com/padmanabhpvdev/music-player.git
```
Head into the location after installation:
```
cd music-player
```
Install the required packages using `npm` command:
```
npm install
```
Run the application:
```
npm start
```
>[!NOTE]
>To add new songs, just add details to *src/playlists.js* file with **Song ID**,**Song Name**,**Artist Name**,**Song URL** and **Song Thumbnail**.
>Also you can add new songs/audio files to the *public/songs/* folder and add the <songname>.<extension> to the playlist.
## Enjoy 🍻
